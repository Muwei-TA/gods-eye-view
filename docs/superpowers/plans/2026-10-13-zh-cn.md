# 简体中文 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为现有前端加入可持久化的中英文选择，并翻译应用自有操作和状态文案。

**Architecture:** 使用显式语义键、纯语言核心和独立 DOM 适配器。模板使用明确翻译标记，动态 UI 在生成文案时调用翻译函数；业务 ID 和外部数据保持原样。

**Tech Stack:** 原生 JavaScript、Node 24、Vite、现有 Node 测试和 Puppeteer。

**Spec:** `docs/superpowers/specs/2026-10-13-zh-cn-docker-design.md`

## Global Constraints

- 支持 `en` 和 `zh-CN`；浏览器 `zh`、`zh-CN`、`zh-SG`、`zh-Hans` 选择简体中文。
- 用户偏好优先于浏览器语言；无匹配时回退英文。
- 语言切换保存偏好并重载当前 URL，不删除分享链接参数。
- localStorage 失败不阻止启动；词典输出普通字符串，遵守现有 HTML 转义。
- 不改业务 ID、协议值、呼号、第三方数据、图标文本及来源署名。
- 使用当前隔离 checkout，保持每个功能里程碑独立提交。

## Review Focus

- 存储被浏览器拒绝时仍可初始化语言：任务 1 验证抛异常的存储适配器。
- 插值参数包含 HTML 时不成为注入入口：任务 1 验证纯字符串与 DOM 文本插入。
- 复杂按钮包含图标和子节点：任务 1 验证翻译不替换容器的完整 HTML。
- 英文协议字段不能随着中文 UI 改变：任务 2 验证 value、data 属性及分享链接不变。
- 开放面板的动态更新不能把中文覆盖回英文：任务 2 浏览器验证图层及天气状态更新。

### Task 1: 语言基础（里程碑 1）

**Files:**
- Create: `src/i18n/core.js`, `src/i18n/messages.js`, `src/i18n/dom.js`, `src/i18n/core.test.mjs`, `src/i18n/dom.test.mjs`。
- Modify: `src/main.js`, `src/ui/templates/scene-chrome.html`, `src/ui/styles/controls.css`, `src/ui/styles/foundation.css`。
- Modify when required by actual import edges: `scripts/package-boundaries.json`。

**Interfaces:**
- `normalizeLocale(value: string): 'en' | 'zh-CN' | null`。
- `resolveLocale({saved, languages}): 'en' | 'zh-CN'`。
- `translate(key: string, parameters: object = {}, locale: string = activeLocale): string`，缺少中文键回退英文。
- `initializeLanguage({document, storage, navigator, reload}): {locale, dispose}`，启动时应用标记，选择变更时保存并调用 reload。
- DOM 标记为 `data-i18n`（文本）及 `data-i18n-title`、`data-i18n-placeholder`、`data-i18n-aria-label`（对应属性）。

- [ ] 编写纯核心测试：保存英文覆盖中文浏览器、中文别名、繁体/未知语言回退、具名插值、缺失键回退；DOM 测试覆盖存储异常、选择后重载、图标节点保留和 `lang` 更新。
- [ ] 运行 `node --test src/i18n/*.test.mjs`，确认因缺少上述行为失败。
- [ ] 实现语言核心、基础双语词典和 DOM 适配器；在 `src/main.js` 创建应用前初始化语言。
- [ ] 在 `scene-chrome.html` 增加 `English / 简体中文` 入口；加入中文字体回退和选择器样式。
- [ ] 运行新增测试、`npm run build`、`npm run check:boundaries`；用浏览器验证切换和刷新后的偏好。
- [ ] 运行 `npm test`，读取完整结果，解决引入的回归后提交 `feat: add persistent English and Simplified Chinese selection`。
