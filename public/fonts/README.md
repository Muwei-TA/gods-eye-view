# Bundled icon font

`material-symbols-outlined-400.woff2` is the unmodified Latin 400 normal font
from `@fontsource/material-symbols-outlined` version **5.3.9**, fetched from the
npm registry with npm's package integrity verification. Original author: Google.
License: SIL Open Font License 1.1; see `LICENSE-material-symbols.txt`.

The application names the CSS family `GEV Material Symbols` so it can render
icons when external Google Fonts access is unavailable. The remote subset link
is retained for its existing glyph inventory, but core icon rendering uses this
local asset. Font bytes are included in the Vite build and Docker image.
